# The Tinkerer 简体中文汉化

The Tinkerer（机械师）的非官方简体中文翻译补丁。原角色作者为 HantaFanta，BaseLib 作者为 Alchyr。

## 使用

在 Steam 创意工坊订阅本补丁、The Tinkerer（项目 3747571123）和 BaseLib（项目 3737335127）。游戏语言选择“简体中文”，在 Mod 列表同时启用这三个项目并重新启动。

本补丁只包含中文文本和显示提示，不包含原角色的 DLL、美术或玩法资源，也不修改其机制。游戏按依赖关系在原 Mod 之后加载汉化。停用本补丁并重启即可恢复英文。

## 内容

- 8 个语言表、479 条词条，含 96 张卡牌名称和描述。
- 角色介绍、古神对话、机器人关键词、能力、遗物、药水和附魔。
- 动态数量词、抽牌和升级提示、能力动态描述及机器人悬浮提示。

The Tinkerer 译为“机械师”，Oil 译为“燃油”，Bot 译为“机器人”，Power 译为“充能”。数值变量、升级高亮、能量图标、条件分支和富文本标签保留。

## 兼容与验证

针对原 Mod v1.0 制作，已在游戏 v0.111.0、BaseLib v3.4.7 下验证。479条词条通过游戏格式校验；16个动态文本用例通过，原包与汉化包实际资源加载、补丁初始化和中文语言表合并均通过。

尚未进行完整战斗测试或逐张卡牌排版检查。原 Mod 更新后，新词条可能暂时回退英文。原版迅捷机器人的语言表写“抽2张牌”，代码里的悬浮提示写“抽1张牌”；汉化保留原文数值。原版空故事文本和内部动作字段保持原样。
